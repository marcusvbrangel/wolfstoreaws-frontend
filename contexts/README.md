# Contextos do projeto

Esta pasta preserva o contexto técnico durável da Wolf Store para próximas
sessões de desenvolvimento.

- [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md): fonte principal de contexto,
  arquitetura, fluxos, invariantes, mapa de arquivos, estado verificado e
  pontos de evolução.
- [`01-feature/initial-integration-with-backend-catalog.md`](01-feature/initial-integration-with-backend-catalog.md): integração inicial da lista de produtos.
- [`01-feature-event-reading-direct-from-api-get-list.md`](01-feature-event-reading-direct-from-api-get-list.md): atualização do catálogo nos eventos críticos da jornada.

Antes de alterar o projeto, leia `PROJECT_CONTEXT.md` e confirme se o commit e
a data do snapshot ainda correspondem ao estado atual. Depois de uma mudança
arquitetural relevante, atualize o documento.
